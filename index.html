Research focus

My doctoral research examined how changing the number of training tokens affects parameter efficiency. I use controlled experiments and compute-aware measures to ask not only how a model performs, but what the training run costs.

That work now informs my interest in practical, resource-conscious machine learning and in making software development education relevant to the tools students will encounter.
